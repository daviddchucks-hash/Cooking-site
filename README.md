# Chef Master

## Overview
Chef Master is a responsive website for a cooking company that offers cooking classes, personal chef services, and catering services. 

## Files Included
- `index.html`: Main HTML file.
- `style.css`: Styles for the website.
- `script.js`: JavaScript for form handling.
- `manifest.json`: Web app manifest for PWA.

## Getting Started

1. **Clone the repository**:
   ```bash
   git clone <repository-url>
   cd chef-master
   ```

2. **Open the index.html file** in your browser to view the website.

3. **For Deployment**:
   - Host the files on a web server like Nginx or Apache.
   - Ensure the server serves the `index.html` file as the main entry point.
   - Optionally, set up HTTPS for security.

## Key Design Decisions
- **Mobile-first Design**: The website is designed to be responsive and user-friendly on all devices.
- **Semantic HTML**: Used meaningful HTML elements to enhance accessibility and SEO.
- **JavaScript for Validation**: Client-side validation for the contact form is implemented for better user experience.

## Future Enhancements
- Implement a back-end service for handling form submissions.
- Add more interactive features, such as a recipe blog or user accounts.
